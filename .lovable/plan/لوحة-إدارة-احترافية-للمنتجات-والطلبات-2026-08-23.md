# لوحة إدارة احترافية للمنتجات والطلبات

تطوير صفحتَي المنتجات والطلبات في لوحة التحكم إلى نظام إدارة تجارة إلكترونية بمستوى Amazon/Shopify، بهوية عربية RTL فاخرة تناسب متجر التجميل، مع الحفاظ على كل المنطق الحالي (الأسعار متعددة العملات، الأقسام المتعددة، الولاء، الفواتير، الواتساب).

## 1. صفحة المنتجات
- شريط إحصائيات أعلى الصفحة: إجمالي المنتجات، المتوفرة، مخزون منخفض (≤3)، نفدت الكمية — وكل بطاقة قابلة للنقر لتفلتر القائمة.
- بحث ذكي فوري بالاسم أو رمز المنتج (SKU)، مع فلاتر: القسم، حالة المخزون، الحالة (مفعّل/معطّل)، وفرز (الأحدث، السعر، المخزون، الأكثر مبيعاً).
- عرض مزدوج: بطاقات على الجوال، جدول مضغوط على الشاشات الكبيرة (صورة، الاسم، SKU، القسم، السعر/سعر الخصم، المخزون، الحالة، إجراءات).
- تعديل سريع مباشر من الصف: تغيير المخزون وتفعيل/تعطيل المنتج بدون فتح النافذة، وحذف بتأكيد.
- شارات تنبيه: «مخزون منخفض»، «نفد»، «مميّز»، «الأكثر مبيعاً».
- ترقيم صفحات (Pagination) بحجم 25/50/100 لدعم آلاف المنتجات دون بطء.

### حول SKU
لا يوجد حقل SKU في قاعدة البيانات حالياً (تم التحقق من جدول `products`). سيتم إضافة عمود `sku` نصي اختياري مع فهرس فريد، وتوليد رمز تلقائي عند إنشاء منتج جديد (مثال: `PR-1025`)، مع إمكانية تعديله يدوياً وعرضه في المنتجات والفواتير.

## 2. صفحة الطلبات
- بطاقات إحصائية أعلى الصفحة (موجودة جزئياً): إجمالي، جديدة، قيد التجهيز، شحن، مكتملة، مدفوعات معلقة — قابلة للنقر كفلاتر.
- بحث برقم الطلب/اسم العميل/الجوال، وفلاتر الحالة وحالة الدفع والتاريخ (اليوم، 7 أيام، 30 يوم).
- قائمة مضغوطة احترافية + لوحة تفاصيل جانبية (Drawer) تفتح الطلب بالكامل:
  - بيانات العميل (الاسم، الجوال، المدينة/المديرية، العنوان، ملاحظات).
  - المنتجات مع الصور والكميات والأسعار والمجاميع (المنتجات + التوصيل = الإجمالي).
  - الدفع: الطريقة، الحالة، صورة الإشعار/الحوالة إن وُجدت.
  - Timeline مرئي لمسار الطلب: جديد ← تأكيد ← تجهيز ← شحن ← تسليم ← مكتمل، مع تمييز الخطوة الحالية.
  - إجراءات سريعة: تقدّم للحالة التالية بزر واحد، تغيير حالة الدفع، واتساب برسائل جاهزة، طباعة الفاتورة، حذف.
- ترقيم صفحات مع تحميل مقسّم لدعم آلاف الطلبات.

## 3. لوحة النظرة العامة (Dashboard)
- تحسين بصري للبطاقات (تدرجات ذهبية/وردية خفيفة، أيقونات ملوّنة، أرقام أوضح) وجعلها روابط سريعة للصفحات المفلترة.
- إبقاء الرسم البياني والقوائم الحالية مع تنسيق أنظف على الجوال.

## 4. التجربة والأداء
- RTL كامل، تباعد متّسق، حواف دائرية وظلال ناعمة من نظام الألوان الحالي (بدون ألوان ثابتة).
- الجوال: بطاقات بعمود واحد، أزرار كبيرة، فلاتر داخل شريط منسدل. الكمبيوتر: جداول كثيفة المعلومات.
- تقليل الاستعلامات: جلب مقسّم بترقيم بدل تحميل كل الصفوف، وحساب الإحصائيات على مستوى قاعدة البيانات حيث يلزم.

## ملاحظات تقنية
- تعديل قاعدة بيانات واحد: إضافة `sku` إلى `products` + فهرس فريد + تعبئة أرقام للمنتجات الحالية.
- الصفحات المتأثرة: `admin.products.tsx`، `admin.orders.tsx`، `admin.index.tsx`، ومكوّنات مشتركة جديدة للبطاقات الإحصائية وشريط الفلاتر ولوحة التفاصيل الجانبية.
- لا تغيير على منطق الولاء أو الفواتير أو رسائل الواتساب — إعادة استخدامها كما هي.
