# طلب تنفيذ من Lovable: ربط Supabase وتجهيز المخطط

## الهدف

اربط مشروع Lovable الحالي، المرتبط بمستودع `zeyadgp/ehabstore`، بمشروع Supabase القائم المملوك للمستخدم:

- اسم المشروع: `Ehab Store Database`
- Project ref: `wibdhbjeirhpewnaejoq`
- المنطقة: `eu-central-1`

لا تنشئ مشروع Supabase جديدًا، ولا تستخدم زر Remix، ولا تغيّر أو تحذف أي مشروع آخر.

## قواعد حماية البيانات

نفّذ التغييرات بعد عرض خطة SQL وموافقة المستخدم عليها. لا تستخدم `DROP`, `TRUNCATE`, أو إعادة إنشاء الجداول. لا تعدّل البيانات الموجودة إلا بطلب مستقل ومحدد. أي تغيير لاحق في المخطط يجب أن يكون migration جديدًا داخل `supabase/migrations/`، مع الحفاظ على migrations السابقة وعدم تعديلها بأثر رجعي.

## المطلوب من Lovable

1. افتح **More → Cloud → Already have a Supabase project? Connect it here**.
2. اربط مؤسسة Supabase التي تحتوي مشروع `Ehab Store Database`.
3. اختر المشروع ذي المرجع `wibdhbjeirhpewnaejoq`، ثم تحقق من أن اسم المشروع وحالته ظاهران في Cloud.
4. اجعل إعدادات التطبيق تستخدم عنوان المشروع المقابل للمرجع الجديد ومفتاح النشر العام الخاص به عبر Secrets أو Environment Variables الآمنة. لا تضع أي مفتاح سري داخل GitHub.
5. راجع migrations الموجودة في المستودع، وشغّلها بالترتيب الزمني على قاعدة البيانات الجديدة فقط. لا تشغّلها على قاعدة الإنتاج القديمة أو على مشروع غير مقصود.
6. بعد التنفيذ، تحقّق من الجداول وRLS وTriggers وStorage buckets، ثم أعد توليد `src/integrations/supabase/types.ts` إذا كان ذلك مطلوبًا.
7. اختبر الصفحة الرئيسية والمنتجات والتصنيفات والعملات والإعدادات والتقييمات وتسجيل الدخول ولوحة الإدارة دون تعديل بيانات الاختبار الحالية.

## ملاحظة عن البيانات القديمة

الفحص الحالي أظهر أن المشروع المختار لا يحتوي جداول عامة أو migrations مسجلة. إذا كانت بيانات النسخة المنشورة في Lovable Cloud مطلوبة، فلا تعتبر هذه القاعدة الجديدة نسخة منها تلقائيًا؛ يجب أولًا تصدير بيانات Lovable Cloud واستيرادها بخطة منفصلة ومراجعة دقيقة. لا تبدأ هذا الاستيراد ضمن طلب ربط المخطط إلا بعد موافقة صريحة.

## النتيجة المطلوبة

بعد إتمام الربط والتنفيذ، أبلغ المستخدم باسم مشروع Supabase المتصل، وعدد migrations التي نُفذت، ونتيجة فحص الجداول وRLS وStorage، وأي تحذير قبل تشغيل التطبيق على البيانات الجديدة.
