# الخطة التالية لمشروع «إيهاب ستور للعناية والتجميل»

## الهدف
إصلاح عرض التصنيفات الفرعية في لوحة التحكم، إضافة صفحة المفضلة، تلميع الواجهة، ثم النشر.

## 1. إصلاح التصنيفات الفرعية في لوحة التحكم
- عرض التصنيفات الرئيسية كقائمة منسدلة/شجرة بدلاً من الشبكة المسطحة.
- تحت كل تصنيف رئيسي يظهر زر «+ إضافة فرعي» يفتح حقل إدخال لاسم التصنيف الفرعي.
- عرض التصنيفات الفرعية مدمجة ومؤشرة بمسافة بصرية تحت التصنيف الرئيسي.
- الحفاظ على إمكانية تعديل الاسم والترتيب والصورة والحذف لكل تصنيف.

## 2. إضافة صفحة المفضلة
- إنشاء مسار `/favorites` يعرض المنتجات المحفوظة محلياً.
- إضافة أيقونة قلب في بطاقة المنتج وفي صفحة تفاصيل المنتج للإضافة/الإزالة.
- إضافة رابط «المفضلة» في الهيدر (سطح المكتب) والقائمة الجانبية (جوال).
- رسالة حالة فارغة جذابة عند عدم وجود مفضلات.

## 3. تلميع سريع
- التأكد من ظهور عدد عناصر المفضلة بجانب أيقونة السلة/المفضلة.
- تحسين حالة التحميل والفارغ في صفحة المنتجات.

## 4. جاهزية النشر
- التحقق من العناوين والأوصان (meta) في كل المسارات.
- النشر عبر زر Publish للحصول على رابط عام دائم.

## ملاحظة تقنية
- لا حاجة لتغيير قاعدة البيانات؛ التصنيفات الفرعية موجودة (`parent_id`) والمفضلة محلية.
- سأستخدم المكتبات الموجودة: React Query, TanStack Router, Tailwind, shadcn/ui, Lucide.
