# تحليل وتقييم نظام «إيهاب ستور للعناية والتجميل»

آخر تحديث: أغسطس 2026

## 1. نظرة عامة
متجر إلكتروني عربي (RTL) لمنتجات العناية والتجميل، مبني على TanStack Start + React + Tailwind،
مع قاعدة بيانات وتخزين ومصادقة على Lovable Cloud، ولوحة تحكم كاملة للمشرف، وطلبات عبر واتساب.

## 2. الوحدات الحالية
| الوحدة | الحالة | ملاحظات |
| --- | --- | --- |
| الواجهة العامة (رئيسية/منتجات/منتج/عن/تواصل) | مكتملة | تصميم ذهبي فاخر، RTL، صور موقّعة من تخزين خاص |

## 3. الأمان
- تفعيل RLS على كل الجداول، وصلاحيات الكتابة محصورة بدور `admin` عبر دالة `has_role` (security definer).
- الأدوار في جدول منفصل `user_roles` (لا يوجد عمود دور داخل جدول المستخدمين) — يمنع تصعيد الصلاحيات.
- تخزين الصور في حاوية خاصة، والعرض عبر روابط موقّعة قصيرة العمر.
- دوال الخادم الحساسة تتحقق من دور المشرف قبل التنفيذ.
- تحذيرات المدقّق الحالية تخص دوال `security definer` عامة بالتصميم (`has_role`, `admin_exists`, `claim_first_admin`) وهي مقصودة.

## 4. الأداء
- استعلامات React Query مع `staleTime` مناسب وتقليل إعادة الجلب.
- تحميل كسول للصور + `decoding=async`.
- توصية: تقسيم استعلام المنتجات إلى صفحات (pagination) عند تجاوز ~200 منتج، وإضافة فهارس على
  `products(category_id, status, created_at)` و`categories(parent_id)`.

## 5. تحسينات مستقبلية مقترحة (بالأولوية)
1. **صفحة المفضلة**: عرض المنتجات المحفوظة محليًا في صفحة مستقلة، ومزامنتها للمستخدم المسجّل.
2. **تقييمات حقيقية للمنتجات**: جدول `product_reviews` مع متوسط تقييم يظهر على البطاقة بدل النجوم الثابتة.
3. **بحث أسرع**: بحث نصي في قاعدة البيانات (`pg_trgm`) بدل الفلترة في المتصفح.
4. **معرض صور للمنتج**: صور مصغّرة قابلة للتنقل + تكبير عند التمرير.
5. **كوبونات وخصومات**: جدول كوبونات مع نسبة/قيمة وتاريخ انتهاء وتطبيقها في الدفع.
6. **تتبع الطلب للعميل**: رابط عام بالرقم يعرض حالة الطلب فقط.
7. **إشعارات**: بريد أو واتساب تلقائي عند تغيير حالة الطلب.
8. **تقارير المبيعات**: رسوم بيانية للمبيعات اليومية/الشهرية وأفضل المنتجات في لوحة التحكم.
9. **SEO متقدم**: بيانات منظمة JSON-LD لكل منتج (السعر والتوفر) وخريطة موقع `sitemap.xml` ديناميكية.
10. **صور OG ديناميكية** لكل منتج لتحسين شكل الروابط عند المشاركة.
11. **إدارة المخزون**: خصم المخزون تلقائيًا عند اكتمال الطلب وتنبيه عند انخفاضه.
12. **دعم لغة ثانية (إنجليزي)** مع تبديل الاتجاه.

## 6. مخاطر ونقاط انتباه
- الاعتماد على واتساب لإتمام الطلب يجعل التأكيد يدويًا؛ يفضّل لاحقًا بوابة دفع.
- المفضلة محلية فقط، تُفقد عند تغيير الجهاز/المتصفح.
- الروابط الموقّعة للصور تنتهي بعد 24 ساعة؛ يعاد توليدها تلقائيًا عند التحديث.
